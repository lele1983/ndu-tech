01 · Come funziona

Tre passi.
Niente infrastruttura da costruire.

Niente API custom, niente migrazioni, niente lock-in. Connetti i tuoi sistemi al gateway tramite Model Context Protocol — lo standard aperto creato da Anthropic. I tuoi dati restano dove vivono.

01

Ti connetti.

Aggiungi NDU MCP Gateway al tuo Claude, ChatGPT, Cursor o a qualsiasi client compatibile MCP. Un clic e sei dentro.

→ Compatible with Claude Desktop · ChatGPT · Cursor · MCP-native clients
02

Ti autentichi.

OAuth in browser, una sola volta. Le credenziali vivono crittografate sul gateway, mai sul client AI.

→ OAuth 2.1 · SSO ready · token rotation · audit log
03

Lo usi.

Chiedi all'AI quello che ti serve — risponderà con i dati reali del tuo business + i dati di mercato che hai abilitato. Niente CSV, niente dashboard da consultare.

→ Natural language → real-time data → citation-grade output

05 · La tua sicurezza

I tuoi dati.
Le tue regole.

Il gateway è la porta — non è il magazzino. I tuoi dati non passano mai dai nostri server in chiaro né alimentano modelli di training.

↯

OAuth 2.1 + audit log

Token a scadenza, rotation automatica, audit trail completo. Sai sempre chi ha chiesto cosa e quando.

⌧

Zero training

I tuoi dati non finiscono in nessun modello, neanche per fine-tuning. Contrattualizzato negli MSA.

§

Ambienti dedicati

Tenant isolato per cliente Enterprise. SSO, IP allowlist, perimetri per ruolo. Pronto per il tuo legal.
